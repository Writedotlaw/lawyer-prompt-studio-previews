## Release verification

Its artifacts contain the HTTP verification result, browser report, and screenshots. Consult the completed run rather than assuming that a commit or submitted deployment succeeded.

Browser checks cover every chapter and exercise, help controls, search, the interactive workflow, notes, reload persistence, and backup restoration in a fresh browser.
